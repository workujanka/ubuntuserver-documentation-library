# Linux Basics — Complete Course (01–30)
# --------------------------------------
# This repository contains a structured Linux learning path from fundamentals
# to automation. Lessons are numbered and intended to be followed in order.
#
# Goals:
#   - build strong Linux command-line confidence
#   - learn practical sysadmin workflows
#   - develop scripting + Git skills
#   - progress into containers, virtualization, and automation
#
# All lessons are written in a beginner-friendly style with # comments.

# 18 — System Performance Tuning (sysctl, ulimit, limits.conf)

# 20 — Bash Scripting Basics
# 21 — Bash Scripting Intermediate
# 22 — Bash Scripting Advanced
# 23 — Git Basics
